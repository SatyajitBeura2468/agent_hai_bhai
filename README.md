# Agent Hai Bhai — Indian Railway Station SVG Experience

A **single-file HTML** experience featuring an **ultra-detailed Indian railway station scene** built with **inline SVG, CSS, and JavaScript**.  
It is immersive, lively, richly layered, and includes **browser-generated station ambience and train sounds**.

## ✨ Highlights

- **Single-file experience** with no framework or build step.
- A cinematic Indian railway station at blue hour.
- Animated locomotive, coaches, wheels, smoke, passengers, flag, birds, station clock and LED board.
- Indian details including multilingual signage, a chai stall, platform markings and the tricolour.
- Procedural Web Audio soundscape with:
  - crowd murmur
  - rail and train rumble
  - station chimes
  - a layered train horn
- Responsive layout for desktop and mobile browsers.
